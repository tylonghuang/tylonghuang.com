# tylonghuang.com

Personal site for Long Hoang Nguyen — live at [tylonghuang.com](https://www.tylonghuang.com).

One page, no framework, no bundler, no dependencies. Custom Hugo theme in
`layouts/`, one CSS file in `assets/css/`, and a hand-drawn origami dragon that
draws itself in once per visit. Deployed to Netlify.
